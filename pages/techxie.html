TechXie is a student-focused file storage platform that allows users to securely upload, organize, and manage their digital content — including videos, PDFs, images, and documents. Built using Node.js with Express and MongoDB, the project features a complete backend API developed from scratch, along with robust session-based authentication. Currently, files are stored locally on the server, with plans to integrate cloud storage in the future. Users can create folders, rename, delete, and download files through a clean HTML/CSS interface. The UI is fully responsive and includes manually designed SVG components, with a custom scroll-kit (scrollbar UI enhancement) under development for a more polished experience. While security hardening and cloud deployment are in progress, TechXie already demonstrates full-stack development principles, including user session management, dynamic file operations, and modular API structure. Developed as a hands-on learning project, it serves as a strong foundation for students exploring backend systems, file handling, and real-world web app architecture.
